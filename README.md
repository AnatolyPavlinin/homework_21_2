### Домашняя работа по верстке
#### Задание 1
С помощью Bootstrap собераем представленные  прототипы для дальнейшей работы над проектом. 
Результатом работы являются HTML-документы со структурой страниц и подключенными к ним Bootstrap-стилями.
Отсутствует перелинковка, т.к. в задании указано не было.
Макеты собираем не один в один, только структурно похожие
